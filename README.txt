O-GA AI Studio policy website (draft)

Files:
- index.html: landing page
- privacy.html: privacy policy draft
- terms.html: terms of service draft

Before publishing:
1. Replace every [bracketed placeholder].
2. Confirm the actual operator identity and contact details.
3. Identify the exact AI API providers and link their terms/privacy documents.
4. Verify exactly what prompts, uploads, outputs, logs, and account data are collected, transmitted, stored, and deleted.
5. Set an accurate age policy and review provider age restrictions.
6. Select governing law with appropriate legal advice.
7. Obtain legal review for the countries where you intend to offer the service.

Important:
These are drafting templates, not legal advice and not a representation that the service already has the described systems or safeguards. Do not publish claims that are not true of the live implementation.

Publishing with GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository (for example: oga-ai-studio-policy).
3. Upload index.html, privacy.html, and terms.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment. GitHub will show the public website URL in Settings > Pages.
8. Test the homepage and both policy links.

GitHub Pages on GitHub Free requires a public repository. The website and repository contents are public.
